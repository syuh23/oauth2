# DAWN
취준생 올인원 집중 플랫폼

NestJS(백엔드) + React(프론트엔드) 기반의 **취업 준비 + 집중 학습** 통합 플랫폼입니다.  
풀스택 개발을 공부하며 진행하는 프로젝트로, MVP부터 확장 기능까지 단계적으로 구현할 수 있도록 설계했습니다.


### 프로젝트 목표
- 취업 준비 과정에서 필요한 정보를 한곳에서 관리
- 공부 집중/기록/랭킹 기능으로 꾸준한 학습 루틴 형성
- OAuth2 + JWT + 권한 분리 + 결제 플랜을 통한 서비스 확장성 확보


### 기술 스택

#### Frontend
- React (Vite)
- TypeScript
- Vercel (배포)

#### Backend
- Node.js + NestJS
- TypeScript
- OAuth2 + JWT
- WebSocket

#### Database / Infra
- PostgreSQL
- Redis
- Notion
- Figma
- Postman


### 핵심 기능

#### 인증 / 인가
- Social Login (OAuth2)
  - Google
  - GitHub (확장)
    - GitHub 연동 시 잔디(기여 기록) 표시
- JWT 인증
- 권한 (Role/Plan)
  - Basic / Premium 기능 분리

#### 취업 정보 기능
- 개인 취업 정보 저장 공간
  - 지원 회사
  - 전형 단계
  - 합격/불합격 여부
  - 메모
- 리스트 형태로 빠르게 조회/정리

#### 커뮤니티
- 게시판
  - 전형 후기
  - 이력서/포트폴리오 꿀팁
  - 공고 공유 (링크)
- 향후 외부 채용 플랫폼 연동(사람인/잡코리아 등) 검토

#### 온라인 스터디 카페
- 스터디룸 생성/신청/수락/퇴장/권한 관리
- 집중 타이머
- 공부 시간 저장
- 실시간 랭킹 (확장)
- 태그 기반 스터디룸 추천 (확장)
- 목표 설정 (확장)

#### 결제 / 플랜
- 월 구독 결제(PG)
- 프리미엄 기능
  - 프리미엄 스터디룸
  - 심화 통계 리포트

#### 통계
- 총 공부 시간 집계
- 연속 학습 일수
- 주/월 단위 통계
- 목표 달성률 리포트 (확장)
